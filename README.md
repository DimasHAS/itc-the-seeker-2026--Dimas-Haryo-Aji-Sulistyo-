# itcirectory

## Cara menjalankan aplikasi
1. Buka folder di vscode. Kalau semua file ada warna merah, kemungkinan harus buka terminal dan eksekusi command: flutter pub get
2. Buka main.dart dan start debugging. Windows emulator akan terbuka.
3. Aplikasi akan membuka home page. Di home page berisi deskripsi singkat tentang ITC dan data statistik yang menunjukkan nama jumlah divisi, anggota, dan tahun periode.
4. Di halaman kedua berisi list kepengurusan tiap divisi.
5. Ketika dipencet, akan membuka kartu detail page yang berisi informasi singkat tentang anggota tersebut.
6. Kartu tersebut bisa ditambahkan ke list favorit dengan cara menekan tombol hati di sebelah nama hingga berubah ke warna merah.
7. Setelah berhasil ditambah, kembali ke list page dan muncul list favorite di atas. Begitu juga ketika di unfavorite, list akan hilang.
8. Pada detail page juga terdapat tombol chat berwarna hijau yang akan membawa ke laman whatsapp bisa chat (tapi semua disini masih menggunakan nomor saya).
