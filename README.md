# itcirectory

## Cara menjalankan aplikasi
1. Buka vscode, buka main.dart, dan start debugging. Windows emulator akan terbuka.
2. Aplikasi akan membuka home page. Di home page berisi deskripsi singkat tentang ITC dan data statistik yang menunjukkan nama jumlah divisi, anggota, dan tahun periode.
3. Di halaman kedua berisi list kepengurusan tiap divisi.
4. Ketika dipencet, akan membuka kartu detail page yang berisi informasi singkat tentang anggota tersebut.
5. Kartu tersebut bisa ditambahkan ke list favorit dengan cara menekan tombol hati di sebelah nama hingga berubah ke warna merah.
6. Setelah berhasil ditambah, kembali ke list page dan muncul list favorite di atas. Begitu juga ketika di unfavorite, list akan hilang.
7. Pada detail page juga terdapat tombol chat berwarna hijau yang akan membawa ke laman whatsapp bisa chat (tapi semua disini masih menggunakan nomor saya).
